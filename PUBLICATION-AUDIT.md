# Publication audit — release candidate, 2026-10-04

Scope: the entire existing project directory classified for publication; publishable source/tests/scripts/config/docs and curated evidence inspected, generated dependency/cache/build/reproduction trees explicitly excluded. Review did not change architecture, test expectations or the frozen mismatch fixture. Exact staged/tracked inventory is checked by npm run audit:publication; source/material scans add independent checks. This is publication hygiene, not a formal security audit/legal ownership certification.

Public files: first-party src/tests/integrations/scripts; root package/lock/config/tsconfigs and .env.example; workflow; current public docs; standard LICENSE/notices; curated evidence/public. Exclusions: node_modules, caches/downloads, dist, reproduction and release checkouts, raw evidence outside public, historical private reports/spec notes, real .env files, logs/temporary/backup files and OS artifacts. .gitignore enforces this boundary. Binary dependencies/builds are not redistributed.

The standard Apache-2.0 text was retrieved from https://www.apache.org/licenses/LICENSE-2.0.txt; project code is offered under that license in the candidate, without inventing a personal copyright owner. Direct dependencies declare Apache-2.0; recorded transitives are permissive. This does not certify legal title. Owner should confirm rights/attribution/contact and approve publication before any external action.

Acceptance: staged inventory/manual review + publication scan with zero blocker findings; heuristic secret scan zero; known deterministic material scan zero; locked Git snapshot reproduction passes. Final measured outcome and commit refs: PUBLIC-RELEASE-GATE.md and local evidence/release/committed-snapshot.json. Scans suppress credential values in findings.

Scanner triage: a username substring occurred coincidentally inside immutable public SRI base64, and a timestamp regex resembled a Windows drive. Inspected the exact contexts; the checker now matches account identifier tokens and uses TypeScript AST regex ranges only for path classification. Credential checks still scan full text. No lockfile/runtime safety assertion was weakened.

The mutable PUBLIC-RELEASE-GATE.md/local commit receipt is intentionally outside the publication tree, avoiding self-referential commit hashes and private approval metadata. The public audit, reproducibility command and curated technical evidence are committed. Exact final commit/archive reproduction is recorded in the local gate and ignored evidence/release receipt; it can be shared after owner review.
