## Declaration discrepancy

`npm run typecheck:signer` executes a direct `WalletAccountEvm -> ClientEvmSigner` assignment. TS2322: WDK `address: string` is not assignable to x402 `address: 0x${string}`. WDK also publishes broad string signature returns and a transaction method with a different shape; the first diagnostic is the address property. Runtime exact EIP-3009 preparation and ECDSA verification pass with the raw account. This is a published declaration/interface mismatch, not a failing cryptographic runtime or a project policy defect. The Tether example is JavaScript; its runtime claim holds in this run. [Official guide](https://docs.wdk.tether.io/ai/x402/), [unmodified assignment fixture](integrations/wdk/signer-compatibility.ts).

We did not alter node_modules, suppress the assignment diagnostic, cast the raw account to the interface, or disable x402 spend controls. The product registers the explicit TypeScript composition adapter directly with the official client. It validates and reconstructs the fixed profile before a mandatory policy callback and validates the returned signature. SDK `setSpendControls` explicitly allows the fixed test asset with the same atomic transaction cap; the initial default rejected an unknown simulated asset before our signer ran. Configuring this narrow fixture entry resolved the demonstrated integration defect. [Actual API source C], [official.mjs](integrations/wdk/official.mjs).

The same challenge is conservatively identified by canonical requirement hash: repeated identical terms in one session are denied even if a seller intended a new purchase. No persistent replay/budget ledger, distributed guarantees, or cryptographic proof that a malicious seller's response represents honest settlement is claimed.

The matrix covers only the stated local supported profile. Other networks/assets, compact/EIP-1271 signatures, approvals/Permit2/v1 and real on-chain settlement are NOT_APPLICABLE, not failed/missing requirements for this fund-free scope. Amount/recipient/network/asset/duplicate/expiry/dry-run/policy boundaries are still exercised by all existing official negative cases, now using the adapter. WDK-X402-TYPE-GAP.md and UPSTREAM-ISSUE-DRAFT.md describe current declaration evidence without alleging acknowledged upstream defects or facilitator endorsement.
